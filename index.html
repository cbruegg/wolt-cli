What it covers

Every Wolt surface, in your shell.

From discovery to checkout preview — the same flows you'd click through in the app, scriptable and pipeable.

Discovery & search

List the discovery feed, browse categories, and search venues or items by query. Filter by locale, address, or coordinates.

wolt search venues --query "ramen"

Venue details & menus

Inspect a venue's hours, menu, categories, and item details. Stream menus with --include-options for the full option matrix.

wolt venue menu <slug> --include-options

Cart operations

show, count, add, remove, clear. Add items with arbitrarily nested options the same way the app does.

wolt cart add <venue> <item> --option …

Checkout preview

Run checkout preview to project totals, fees, and delivery cost from your current cart — without ever placing an order.

wolt checkout preview --venue-id …

Profile & orders

Auth status, profile, past orders, saved addresses, payments, and favorites — read-only and respectful of your account scope.

wolt profile orders --limit 20

Token rotation

Auth via --wtoken, refresh with --wrtoken, or cookie pairs. Profiles isolate credentials per environment.

wolt configure --profile-name default …

Pipeable output

Every command emits table, json, or yaml. Pipe straight into jq, yq, or your own scripts.

--format json | jq '.data.items[]'

Location override

Pass --address or --lat/--lon per command. Preview-only — final orders still use your saved Wolt address.

--address "Mannerheimintie 1, Helsinki"
Install

One command. One binary.

Homebrew is the recommended path. Building from source is a single go build.

# Add the tap, then install
brew tap mekedron/tap
brew install wolt-cli
# Single command — tap is added implicitly
brew install mekedron/tap/wolt-cli
# Requires Go 1.26+
git clone https://github.com/mekedron/wolt-cli.git
cd wolt-cli
go build -o bin/wolt ./cmd/wolt
./bin/wolt --help
# No checkout, no install — just run
go run ./cmd/wolt --help
1

Configure a profile

Save your token and refresh token to a named profile. Cookie auth is supported too.

wolt configure --profile-name default \
  --wtoken "<token>" --wrtoken "<refresh>" --overwrite
2

Verify it works

Status checks the loaded profile and validates the token against the API.

wolt profile status --verbose
wolt profile show --format json
3

Run anything

Pipe into jq, save to disk, or feed another script. Output format is yours.

wolt search venues --query "ramen" --format json \
  | jq -r '.data.items[].slug'
Real example

Build a custom WHOPPER meal — end to end.

Five steps, all in your terminal. No order is placed; checkout is preview only.

  1. 01

    Find the venue

    Search for the venue and copy its slug + venue_id.

    wolt search venues --query "burger king" --limit 10 --format json \
  | jq -r '.data.items[] | "\\(.slug)\\t\\(.venue_id)\\t\\(.name)"'
  2. 02

    Inspect the menu

    Pull the menu with the option matrix and locate the item you want.

    wolt venue menu burger-king-finnoo --include-options --format json \
  | jq -r '.data.items[] | select(.name|test("whopper";"i"))
                         | "\\(.item_id)\\t\\(.name)\\t\\(.base_price.amount)"'
  3. 03

    Read the options

    Resolve drink, side, and add-on group IDs to value IDs.

    wolt item options burger-king-finnoo <item-id> --format json \
  | jq -r '.data.option_groups[] | .name as $g | .values[] | "\\($g)\\t\\(.name)"'
  4. 04

    Add to cart with options

    Repeatable --option group=value flags compose the whole order.

    wolt cart add 629f1f18480882d6f02c25f0 676939cb70769df4cec6cc6f \
  --venue-slug burger-king-finnoo \
  --option "69958f7a0ccf540d98667a70=69958f777cb002552fad3d3d" \
  --option "6995b941621e894833915306=6995b93d45f708d8b1ad1345" \
  --option "69958f7a0ccf540d98667a73=69958f777cb002552fad3d51" \
  --format json
  5. 05

    Preview the checkout

    Project items, fees, and totals — nothing is submitted.

    wolt cart show --details --venue-id <venue-id> --format json
wolt checkout preview --delivery-mode standard --venue-id <venue-id>

Honest answers

FAQ

Is this an official Wolt product?

No. wolt-cli is an unofficial, community-built Go CLI. It's not affiliated with, endorsed by, or supported by Wolt. Use it at your own responsibility, and respect their terms of service.

Can it place real orders?

No. The CLI exposes checkout preview only, which projects totals and fees. Final order placement still happens in the official Wolt app or website, using the delivery address selected in your account.

Where is my config stored?

By default at ~/.wolt/.wolt-config.json, or wherever WOLT_CONFIG_PATH points. The file may contain wtoken, wrtoken, and cookies — keep it local and don't commit it. The project's .gitignore already ignores common config patterns.

What about location overrides?

Pass --address or --lat/--lon per command. They affect preview inputs only. Final orders still use your Wolt-saved address. --lat and --lon must be supplied together; --address can't be combined with them.

Which platforms are supported?

Anywhere Go 1.26+ builds: macOS, Linux, and Windows. Homebrew is the smoothest path on macOS and Linux.

How do I report a bug or contribute?

Open an issue or PR on the GitHub repository. Run go test ./... and make lint before submitting.
